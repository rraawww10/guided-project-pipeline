# CLAUDE.md

## What this repo is

A guided-project production pipeline: five agents, six scripts, three human gates.
Turns a one-page idea into a spec, working code, test suite, student skeleton, and instructor session guide.

See `Flow.md` for the design and `README.md` for usage.

## Project structure

```
pipeline/           # orchestrator + all six scripts (Python)
  cli.py            # orchestrator CLI: new, gate, lock, unlock, next, status, ship, watch
  spec_linter.py    # checks spec format and rules
  test_runner.py    # runs verifier-written tests
  cutter.py         # generates student skeleton from cut markers
  deploy_check.py   # install, build, preview link
  guard.py          # PreToolUse hook - enforces write locks
  watchdog.py       # nightly replay of test suites
  state.py          # gate/retry state, 15-retry cap
  selftest.py       # 45 deterministic checks on the scripts
  templates/        # CONTRACT.md (spec.json shape), idea_template.md
.claude/
  agents/           # agent definitions (spec-writer, spec-breaker, builder, verifier, pack-writer)
  skills/           # skill prompts for each agent
projects/<slug>/    # one directory per guided project
  idea.md           # input: one-page idea
  spec.md / spec.json  # the spec (prose + machine contract)
  ambiguity.md      # spec breaker output
  app/              # built project code
  verify/           # verifier-written test suite
  skeleton/         # generated by cutter, never hand-edited
  pack/             # instructor session guides
  .pipeline/        # round history, CONTRACT.md
fixtures/           # test fixtures for selftest
learning/lessons.md # lessons learned - every agent reads this
```

## Key commands

```bash
python3 -m pipeline new <slug>          # scaffold a new project
python3 -m pipeline next <slug>         # what step is next
python3 -m pipeline status <slug>       # gates, retries, tickets
python3 -m pipeline gate <slug> N approve|reject -m "reason"
python3 -m pipeline lock <slug> app     # restrict writes to app/
python3 -m pipeline unlock <slug>
python3 -m pipeline ship <slug>
python3 -m pipeline watch               # nightly watchdog
python3 -m pipeline.selftest            # run 45 deterministic checks
```

## Rules (enforced, not just documented)

1. Every agent has a checker (spec writer -> linter, builder -> test runner, cutter -> skeleton check).
2. Spec Breaker != Spec Writer (separate agents).
3. Builder cannot edit test files - enforced by `guard.py` PreToolUse hook + lock file.
4. `skeleton/` is always generated by `cutter.py`, never hand-edited.
5. The orchestrator is plain code. No agent manages another agent.
6. Retries cap at 15, then a ticket is raised (`state.py`).

## Two critical artifacts

- **`spec.json`** - machine contract read by linter, builder, verifier, and cutter. Shape defined in `pipeline/templates/CONTRACT.md`.
- **Cut markers** - `// >>> CUT <id>` / `// <<< CUT <id>` in app code. Cutter replaces them with TODO hints from spec.json.

## Working conventions

- Run `python3 -m pipeline.selftest` before trusting changes to any script.
- Update `learning/lessons.md` between runs, never during one.
- Commit the approved spec before starting phase 2.
- Every agent reads `learning/lessons.md` before starting.
- The three workflow phases are independent human checkpoints: phase 1 (spec), phase 2 (code), phase 3 (pack). Each stops at its gate.
