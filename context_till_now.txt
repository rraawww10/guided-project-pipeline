## Continuation Update - Create Form Input Fix

The user reported that typing into the Create Project UI disappeared from the input fields.

Root cause:

- `pipeline/ui_static/app.js` auto-refreshes overview data every 5 seconds.
- Each refresh calls `render()`, and `renderCreate()` rebuilt the Create Project form from hard-coded defaults.
- Because the form had no persistent local draft state, partially typed input was wiped on refresh.

What was changed:

- Added a `createDraft` object in `pipeline/ui_static/app.js` to preserve Create Project form values across renders.
- Wired create form `input` and `change` events into that draft state.
- Reset `createDraft` only after successful project creation.
- Added a small `formDirty` guard so background refresh does not wipe in-progress gate/dry-run form notes elsewhere in the UI.
- Added a `Cache-Control: no-store` header in the UI server's `send_bytes()` helper to reduce stale frontend asset issues after UI changes.

- `python -m py_compile pipeline\ui.py` passed.
